      For the team: what this page hands to the pipeline

      When PIPELINE_URL is set at the top of the script, Build sends POST {PIPELINE_URL}/jobs as multipart form data: a manifest field holding this JSON, plus one files part per uploaded file, named {source id}/{path}. The server returns {"job_id"}. The page then polls GET {PIPELINE_URL}/jobs/{job_id}, which returns {"stage": "okf" | "embed" | "cluster" | "name" | "render", "status": "running" | "done" | "failed", "map_url", "regions": [{"name", "count"}]}. Run uv run datamap serve from the repository root and the page connects to the pipeline on its own; opened any other way, it runs in demo mode.
