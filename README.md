## About the snapshots

Each folder is a static copy of the team's repository at the commit shown in the Snapshot column, taken without git history. The original repo has the latest version.

## Use a project

Copy one project by its folder name:

```bash
npx degit 00Zero/claude-impact-lab-seattle-oct-2026/<folder> my-copy
```

For example, `npx degit 00Zero/claude-impact-lab-seattle-oct-2026/neri-cash my-copy`.

Or get everything:

```bash
git clone https://github.com/00Zero/claude-impact-lab-seattle-oct-2026.git
```
