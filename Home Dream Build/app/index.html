Voice settings

Narration uses ElevenLabs when a key is saved. Create one at elevenlabs.io under Developers → API keys and give it Text to Speech and Voices (read) access. It's stored only in this project's .env file on this Mac.

Instagram settings

Connect an Instagram Business or Creator account to publish finished videos.

Link your professional Instagram account to a Facebook Page. Use a Page access token from a Meta app configured for Facebook Login for Business.

Saved on this Mac. The token is never sent back to the browser.

API setup

Token permissions: instagram_basic, instagram_content_publish and pages_read_engagement. Use the linked Instagram account ID, not the Page ID.

For testing, use an account authorized to test your Meta app. Publishing for other accounts requires Meta's access review.
